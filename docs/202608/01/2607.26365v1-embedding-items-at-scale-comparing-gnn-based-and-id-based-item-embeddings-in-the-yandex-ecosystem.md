## 摘要
基于 Transformer 的序列推荐模型处理用户-物品交互序列，高度依赖物品嵌入策略。现有方法要么使用预训练的物品嵌入，要么将其与 Transformer 一起端到端学习。据我们所知，尚无先前工作在大规模工业环境中从成本和质量两方面比较这些方案。本文是一项案例研究，在 Yandex 的两个成熟生产推荐系统（Yandex Market 和 Yandex Music）中比较了预训练的工业图神经网络物品嵌入与端到端可训练的物品嵌入。此外，我们还在从 Yandex Lavka 生产日志中采样的低资源数据集上评估了两种方法，该数据集和代码已公开可用于演示。结果表明，当训练数据有限时，单独的预训练阶段有帮助，但对于在大量数据集上训练的大规模模型则没有明显益处。

## Abstract
Transformer-based sequential recommendation models, which process sequences of user-item interactions, rely heavily on the item embedding strategy. Existing approaches either use pretrained item embeddings or learn them end-to-end with the transformer. To the best of our knowledge, no prior work has compared these options from both cost and quality perspectives in a large-scale industrial setting. This paper is a case study that compares pretrained industrial graph neural network item embeddings with end-to-end trainable item embeddings across two mature production recommendation systems at Yandex: Yandex Market and Yandex Music. We additionally evaluate both approaches on a low-resource dataset sampled from Yandex Lavka production logs, for which both the data and code are publicly available for demonstration purposes. Our results show that a separate pretraining stage helps when training data is limited, but provides no worthwhile benefit for large-scale models trained on extensive datasets.

### 2. 理论与方法
本研究服务于**序列推荐（类比路径/状态预测）**任务，对比了两种交通实体嵌入范式，并被集成到一个生产级的两塔式Transformer排序模型中进行测试。

*   **核心交通任务**：给定用户的出行交互历史序列 $x_u = (i_1^u, i_2^u, ..., i_{l_u}^u)$，预测其下一个将要访问或交互的交通实体（如路段）。该方法聚焦于排序阶段，通过预训练和微调两个阶段训练模型。
*   **对比方法**：
    *   **基于图神经网络的预训练嵌入（GNN Embeddings）**：将用户与交通实体的交互（如通过某路段、在交叉口转弯）建模为**异构图**。采用两种工业级GNN：
        1.  **直推式（Transductive）TwHIN**：将节点直接映射为可训练的嵌入向量矩阵 $\Theta$，通过边重建（如源节点嵌入+关系嵌入与目标节点嵌入点积）和负采样损失进行优化。
        2.  **归纳式（Inductive）MultiBiSage**：将异构图分解为多个**二分图**，利用Transformer聚合节点自身及其邻域的特征，从而学习一个参数化的函数，能泛化到未见节点。
    *   **端到端可训练的ID嵌入（ID Embeddings）**：直接为每个交通实体ID分配一个可学习嵌入，并与下游的Transformer一起从零训练。为解决大规模词汇表问题，使用**多重哈希（Multihash）**技巧，通过多个哈希函数查找嵌入表并聚合，减少碰撞。
*   **下游排序模型架构**：
    *   **实体塔（Item Tower）**：将实体ID嵌入（或GNN嵌入）与实体内容特征（如文本特征）相加，通过残差网络处理，输出L2归一化后的实体表征。
    *   **用户塔（User Tower）**：将出行序列中的每个实体通过实体塔编码后，加上可学习的**动作嵌入**（如点击、购买，可类比为通过、停留等）和**位置嵌入**，送入双向Transformer编码器。取`CLS`令牌对应的输出，经L2归一化后作为用户意图表征。
    *   **预训练与微调**：
        *   **预训练**：采用**下一实体预测**任务，使用采样后的Softmax交叉熵损失，结合批次内负采样。
        *   **微调**：在真实的候选集上，结合**逐点（点击率预测）**和**成对（Pairwise）**排序损失进行训练，优化最终的推荐排序。最终输出的排序分数被视为一个高级特征，输入到一个CatBoost排序器中，评估其增量贡献。

### 3. 数据与实验设计
研究在三个不同规模和特性的Yandex平台生产日志上设计对照实验，以评估嵌入策略的泛化能力。

*   **Yandex Market（类比城市路网大规模出行）**：
    *   **数据范围**：一整年的生产日志，包含千万级（$O(10^7)$）的交通实体（如路段），用户动作包括点击、加购、购买等。测试集为训练期之后两天的数据。
    *   **方案设计**：对比**TwHIN嵌入**、**MultiBiSage嵌入**、**ID嵌入**，以及**TwHIN与ID嵌入组合**。GNN嵌入仅覆盖热门实体，其余实体共享一个嵌入。
*   **Yandex Music（类比共享交通路径选择）**：
    *   **数据范围**：千亿级的用户交互，涉及百万级的轨道（类比为共享设施）。用户动作包括播放时长、喜好、跳过等。
    *   **方案设计**：仅评估**TwHIN嵌入**与**无哈希的唯一ID嵌入**，并增加**TwHIN嵌入微调**（与Transformer联合学习）的实验组。
*   **Yandex Lavka（类比即时配送物流网络，低资源场景）**：
    *   **数据范围**：一年内约1500万用户-实体交互，来自3315个用户和25833个实体（如配送点）。这是一个公开的**低资源数据集**。
    *   **方案设计**：在小规模Transformer模型上，比较非冻结和微调的**TwHIN嵌入**与**端到端ID嵌入**。此场景下直接输出排序分数，不经过CatBoost二次排序。
*   **基准与对比方法**：各实验均以“仅使用内容信息（无行为嵌入）”的模型作为参照基准。最终评估时，以“无该模型评分特征”的CatBoost排序器为对比基准，计算性能的相对增量。

### 4. 评价指标与结果
研究采用**离线相对指标增量**来量化不同嵌入策略对最终排序质量的贡献，这可以映射为对交通推荐任务预测准确率的提升。

*   **评价指标**：
    *   **相对nDCG（归一化折损累计增益）差异**：用于评估排序列表的整体质量（Market场景）。
    *   **相对配对准确率（Pair Accuracy）**：衡量模型对正负样本对的相对偏好排序是否正确（Music场景）。
*   **核心定量结果**：
    *   **大规模高资源场景（Market & Music）**：
        *   **端到端ID嵌入**显著优于所有预训练GNN嵌入。例如，在Market的“重定向”（Retargeting）场景，ID嵌入带来+1.486%的nDCG提升，远超TwHIN的+0.943%。在Music场景，ID嵌入（+0.699%）同样优于微调后的TwHIN（+0.524%）。
        *   **组合效应**：在Market中将TwHIN与ID嵌入结合可取得轻微的最高增益（+1.522%），但相较于额外预训练的计算成本，收益提升不够显著，被认为不划算。
        *   **微调效应**：对TwHIN嵌入进行端到端微调后，其性能虽有提升（从0.348%到0.524%），但仍无法超越从头训练的ID嵌入。
    *   **低资源场景（Lavka）**：
        *   **预训练GNN嵌入（TwHIN）展现出明确优势**。即使TwHIN嵌入保持冻结（nDCG@5为0.337），其性能也优于端到端训练的ID嵌入（0.333）。微调后的TwHIN嵌入（0.342）进一步拉开了差距。

### 5. 有效性检验
实验设计具备工业场景下充分的统计严格性和工程有效性。

*   **统计显著性检验**：将所有数据集分为32个同等大小的折，通过**威尔科克森符号秩检验（Wilcoxon signed-rank test）**验证相对提升的显著性，仅报告$p < 0.01$的差异。
*   **多场景稳健性**：结论在电商、音乐流媒体和即时零售三个性质完全不同的业务平台上进行交叉验证，增强了结论的普适性。
*   **模型集成验证**：通过将Transformer评分作为一个新特征输入到最终的生产级梯度提升树（CatBoost）排序器中，评估其“增量”价值，而非孤立地评估模型本身，确保了离线指标与真实业务指标的关联性。
*   **消融实验**：对比了GNN嵌入的冻结与微调状态，以及单一策略与组合策略，清晰揭示了各因素的实际贡献。

### 6. 主要结论与交通工程启示
此项研究为智能交通系统中交通实体表征的工程选型提供了明确、可操作的指导原则：

*   **关键结论**：**端到端学习的ID嵌入在大规模交通数据场景下是“成本-效益”最优方案**。它避开了昂贵、复杂的图构建与预训练流程，仅凭强大的序列模型和数据规模就能学到高质量的实体表征。**图预训练仅在数据稀疏、实体交互有限的低资源场景下才有必要。**
*   **对规划、设计与运营的启示**：
    *   **系统设计**：在为大规模城市路网设计路径推荐、轨迹预测模型时，优先采用高效的哈希ID嵌入方案，可简化系统架构、降低维护成本并显著缩短模型迭代周期。
    *   **资源分配**：只有当处理新建区域、低频访问节点或罕见交通模式时，才应考虑引入图预训练所带来的额外计算与工程开销，以注入结构先验知识。
    *   **模型策略**：将预训练嵌入与端到端嵌入进行组合，虽然可能带来边际提升，但从投入产出比看，通常不是明智的工程选择。

### 7. 优点与创新
*   **填补研究空白**：首次在超大规模的工业级推荐（交通预测）系统中，系统性地从成本和效果两个维度，量化对比图神经网络嵌入与ID嵌入这两种核心表征范式的真实价值。
*   **结论具有颠覆性**：挑战了“预训练总是更好”的直觉，有力证明了数据规模本身的表征学习能力足以超越精心设计的图结构先验。
*   **工业工程完整性**：研究涵盖了文本、图像和纯行为数据，实验过程完整包括了模型预训练、精调，以及作为集成模型特征的上线全流程，结论对工程实践极具说服力。
*   **可复现性贡献**：公开了低资源的Yandex Lavka数据集和完整代码，为学术界和其他工业界在有限资源下的研究提供了基准和验证平台。

### 8. 局限与适用边界
*   **关键假设**：核心假设是ID的基数（词汇量）是可控或可通过哈希有效压缩。当交通实体（如轨迹点）近乎无限且重复率极低时，该结论可能失效。
*   **嵌入技术代表性**：仅比较了直推式TwHIN和归纳式MultiBiSage两种特定的图模型。其他复杂的、基于特征传播的GNN（如GAT， Graph Attention Networks）是否会有不同结论，尚待验证。
*   **数据与行为偏差**：GNN嵌入的性能高度依赖于所构建的异构图质量，且可能放大数据中的流行度偏差（热门实体被更好地表征）。实验中对图进行剪枝和熵过滤试图缓解此问题，但未能完全消除。
*   **可迁移性边界**：结论“大模型无需预训练”的成立，与巨大的训练数据量（年级别、百亿级交互）和模型容量强相关。数据规模和模型规模有一个临界点，低于该临界点时，图预训练的先验知识仍是必要的。
*   **计算成本考量**：报告了GNN预训练的时间成本，但对于线上服务时检索冻结嵌入带来的额外存储与通信开销，以及ID嵌入哈希冲突带来的潜在精度损失上限，缺乏深入的定量分析。
